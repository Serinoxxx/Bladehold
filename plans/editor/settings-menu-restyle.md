# Editor to-do: Settings menu restyle

Not from a plan: a one-off settings-menu restyle on 2026-10-03, built through Unity MCP (connected) and play-checked in Outer Gate and MainMenu. Tick items off as you go and delete the file when it's empty.

The layout is generated by **Bladehold > UI > Rebuild Settings Panel (prefab + open scene)** (`Editor/SettingsPanelBuilder.cs`). It rebuilds the `SettingsPanel` children inside `PauseMenuCanvas.prefab`, every unpacked copy in the open scene, and `RebindRow.prefab`. Don't hand-edit the generated objects: change the builder and re-run it. MainMenu, Demo Scene, Test Scene and Enemy Zoo each have their own unpacked copy, so re-run the "open scene only" menu in each of those scenes after a change.

## Verify first

- [ ] **Back works in both homes.** In the pause menu, Back returns to the main pause buttons (`PauseMenuView.backFromSettingsButton` was re-pointed to the new `BackButton`). In MainMenu, Back runs `MainMenuManager.OnBackToTitle`, a persistent listener the builder carried over. Pad B should do the same in both.
- [ ] **Real rebind round-trip.** Controls tab: click a Keyboard cell, press a key, and check the glyph updates. Then Reset Settings → Reset should put the original glyph back.

## UI review

- [ ] **Look and feel.** Check the Synty art (gold `Frame_Box_Medium_02` window frame, parchment tabs), Texturina headers and Grenze body text. Check that the row hover glow, the gold cell frame and the scale pop feel right. Colours are constants at the top of `SettingsPanelBuilder.cs`.
- [ ] **Gamepad.** LB/RB cycle the tabs (Q/E on keyboard), and the glyphs either side of the tab bar swap with the device. Each tab switch focuses its first control. On Controls, Up from the first rebind row should reach Invert Y, and Down from the last row should reach Reset Settings. The value boxes beside the sliders are skipped on purpose (the pad adjusts the slider itself).
- [ ] **Aspect ratios.** Already checked at 16:9, 21:9 (2560×1080) and 4:3 (800×600). Have a look at 16:10 and on the Steam Deck if you have one.
- [ ] **Hint footer.** Navigate, Select and Back show on a pad only. Each `HintEntry` carries a fixed 160 px label, so the builder overlaps them (spacing −36, scale 0.85). Longer translations (de, ru) may collide. Check them via Language.
- [ ] **Hover and click sounds.** Every control plays the `ClickMMF` cloned from `MenuButton.prefab` when clicked, and a `HoverMMF` on hover/pad focus: the same UI click at about 0.3 volume and pitch 1.55 to 1.7, with a 0.06 s cooldown. There's no dedicated hover clip in the project yet. Swap one in via `SettingsPanelBuilder.CloneHoverFeedback` and re-run the builder.
