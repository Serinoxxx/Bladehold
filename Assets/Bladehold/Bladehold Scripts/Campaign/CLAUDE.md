# Campaign

The macro run structure: an 8-tier branching node map between the Meta Area and the battles.

## Pieces

- **`CampaignGraphSO`**: the graph. **Source of truth is the asset** `Assets/Bladehold/Resources/CampaignGraph.asset`, with one node asset per node in `Resources/CampaignNodes/`. `CampaignManager.ActiveGraph` loads it via `Resources.Load("CampaignGraph")`, and the map scene references it directly. It's generated by `Editor/SetupCampaignPrefabsAndAssets.cs` (**Bladehold/Campaign/Setup All Campaign Prefabs & Scene**) from `BuildDefaultGraph()`. After generation, tweak nodes in the inspector, and don't regenerate over hand edits without checking. `CreateDefaultCampaignGraph()` remains as a runtime fallback.
- **`CampaignNodeSO`**: one node. `nodeId`, `sceneName`, `nodeType`, `tierIndex`, `mapPosition`, `captainName`, `difficultyTier` (Standard/Enraged/Nightmare/Omega), `bountyType`, gold/blood/metal rewards, `nextNodes`.
- **`CampaignNodeType`**: Combat, RestArea, SupplyRoom (unused), FishingPond, PreBoss, NecromancerEncounter, PrincessBoss, NecromancerBoss.
- **`CampaignManager`**: `DontDestroyOnLoad` singleton (auto-creates if missing). Holds current/completed/available node ids, mirrored into `RunSession.Campaign*` so they survive scene loads. `SelectNode` loads the node's scene (resetting `RunSession.CurrentWave = 1` for Combat/PreBoss). `CompleteCurrentNode` unlocks `nextNodes`, pays gold into the run and blood/metal straight to `SaveData`.
- **`CampaignMapUI`**: builds node buttons and path lines at runtime from the graph; starts a new campaign run on first open (`!RunSession.IsCampaignRun`).
- **`CampaignNodeButtonUI` / `CampaignTooltipUI`**: button visuals and hover tooltip.
- **`SupplyRoomController`**: legacy, no node uses it (ponds replaced supply rooms).

## Flow

- Meta `BattlePortal` → `RunSession.StartNewRun` + `CampaignManager.StartCampaignRun` → map. The map has no Return-to-Meta button: the only ways home are death or campaign end.
- Sector victory → `DeathScreen` → `CampaignManager.CompleteCurrentNodeAndOpenMap()`. A battle scene played straight from the Editor has no campaign run, so its victory starts a fresh one and opens the map.
- Rest Area in campaign mode: `RestAreaGate` saves HP ratio + ultimate charge, then returns to the map.
- Fishing: `FishingManager` loads the map directly.
- Each Combat node supplies only `difficultyTier`, `bountyType` and `captainName` to `GameLoopManager`. Wave count and pacing are the same everywhere; scaling with depth is planned (see root CLAUDE.md, "Design direction").

## Bosses (tier 8)

- The Crypt node loads `Bladehold Necromancer Crypt`; `NecromancerConfrontationUI` offers Obey (`DeployToNode("tier8_princess_boss")`) or Defy (the boss fight in the same scene).
- The confrontation is kicked off by `DelayedConfrontationStarter`, which is defined inside `Editor/BuildNecromancerCryptScene.cs`. It gets compiled out of player builds, so **the choice never appears in a build**.
- Boss kills call `CompleteCurrentNode()`; there is no end-of-campaign screen or run reset yet.
