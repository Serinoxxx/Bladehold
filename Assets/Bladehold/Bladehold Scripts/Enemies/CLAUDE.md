# Enemies

## Roster

- **`Assets/Bladehold/Config/Enemies.csv`** is parsed by `EnemyRosterSO`. Columns:
  `id,displayName,health,damage,minGold,maxGold,speed,scale,unlockWave,spawnChance,minSpawn,maxConcurrent,knockbackResistance,enabled`
  - Blank stat cells keep the prefab's SO value.
  - `enabled` = 0 removes the row.
  - The first row (goblin) is the fallback type.
- **`EnemyPrefabMapSO`** (`EnemyPrefabMap.asset`) maps CSV ids to prefabs. Variants are generated by `Editor/EnemyPrefabGenerator.cs` from `Editor/EnemyManifest.cs`; see the `generate-enemy-prefabs` skill. Don't hand-wire them.
- **Spawning in sectors**: `SurvivorsSpawner` admits a type only if `unlockWave <= wave` **and** the id is in that wave's `allowedEnemyIds` (the pacing asset). Today that's goblin, brute, big_ork, bubbler, bomber. Bulwark, Bannerman, Powder Keg, Assassin, Storm Witch and Troll are built but only reachable via the DevConsole or EnemyZoo. **Decided:** they should join sector waves, with difficulty scaling by campaign depth while goblin fodder keeps spawning.

## Behaviour

- Shared pieces:
  - `AIMovement` (NavMesh chase, staggered repaths, avoidance tiers).
  - `AIAnimation` + `LocomotionAnimator` (Synty blend params).
  - `AITargetSelector`.
  - `AIAttack` (basic melee).
  - `CoinDropper`, `Enemy` (kill reporting).
- **Attacks are uneven by design.** Special enemies have telegraphed attacks (Bulwark counter-slam, Kombusta dynamite, Troll slam, bomber, and others). Basic enemies just swing for minor damage when in range, with no telegraph.
- Special attack components sit beside their SOs (`*Attack.cs` + `*AttackSO.cs`), with per-enemy folders for bigger kits (`Bulwark/`, `Bannerman/`, `Bomber/`, `Assassin/`, `Captain/`, …).

## Captains

- `Captain/CaptainKombustaController` (dynamite barrage at range, fire aura up close) and `Captain/CaptainEnemyController` (Fraglob: war cry, stomp, bulwark stance; currently a scaled goblin_brute fallback because the captain prefab slots are empty).
- `GameLoopManager.SpawnCaptainForWave` spawns them on wave 5 and on Enraged-or-higher waves.
